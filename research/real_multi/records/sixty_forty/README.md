# 策略研究记录：sixty_forty

> 类别/途径：**multi_asset** ｜ 类型：cross_section ｜ 方向：只做多

## 一句话思路
经典 60/40：60% 股票(中外宽基等权) + 40% 债券，定期再平衡。

## 收集途径 / 灵感来源
多资产配置——传统 60/40 股债组合。

## 核心假设
股债负/低相关，60/40 是长期稳健的配置基准。

## 参数
- `equity` = 0.6

## 实现要点
- 实现文件：`kairos_strategies/channels/multi_asset.py`（类名对应本策略）。

- 仅使用 numpy/pandas，离线、确定性。
