# 策略研究记录：all_weather

> 类别/途径：**multi_asset** ｜ 类型：cross_section ｜ 方向：只做多

## 一句话思路
全天候(类风险平价)：在风险资产类别间按逆波动分配，类别内等权。

## 收集途径 / 灵感来源
多资产配置——All Weather / 风险平价思想（类别层逆波动简化版）。

## 核心假设
低相关多资产 + 按风险而非资金配置，可在不同宏观环境下更稳健。

## 参数
- `window` = 60

- 仅使用 numpy/pandas，离线、确定性。
