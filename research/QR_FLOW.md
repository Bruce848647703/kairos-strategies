# QR 流程（Quant Research Flow）

本仓库把一个策略从「想法」到「可审计的研究记录」的完整链路固化为可复现流程。
每个策略都走同一条流水线，产物落在 `research/records/<name>/`。

```
收集 → 假设 → 实现 → 回测 → 评估 → 记录 → 复现 → 迭代
```

## 1. 收集（多渠道）
通过多种途径汇集策略想法，按"来源途径"分渠道归档到 `kairos_strategies/channels/`：
- `technical`：经典技术分析（均线、RSI、MACD、布林带、唐奇安/海龟）。
- `momentum`：时序与截面动量、52 周新高、双动量等。
- `meanrev`：均值回归 / 统计套利（z-score、价差、布林回归）。
- `factor`：价格/波动可构造的因子异象（低波动、短期反转、趋势质量等）。
- `volatility`：波动率目标、ATR 突破、波动率状态过滤。
- `crypto`：加密市场实践（网格、定投、24/7 动量、carry 代理）。
- `benchmark`：被动基准（买入持有）作为对照。

> 每个策略的 `source` 字段记录其收集途径/灵感来源，保证可追溯。

## 2. 假设
为每个策略写下**核心假设**（`hypothesis`）：它为什么可能有效、在什么市场性格下有效、
失效条件是什么。假设是后续评估与迭代的依据。

## 3. 实现（统一契约）
- 策略 = `Strategy` 子类，实现 `generate_weights(data) -> 权重面板 (date × asset)`。
- **只用截至当期的信息**；引擎再对权重滞后一期，双重防未来函数。
- long_only 策略权重 ≥ 0；截面策略建议每行绝对权和 ≤ 1。
- 仅用 numpy/pandas，可复用 `indicators.py`；离线、确定性。

## 4. 回测
`engine.Backtester`（向量化）：
- 组合收益 = Σ(上一期权重 × 本期资产收益)。
- 换手 = |目标权重 − 漂移后持有权重| 之和；成本 = 换手 × 单边成本率。
- 输出净收益、毛收益、净值、换手、持仓权重。

## 5. 评估
`metrics.summarize` 产出：累计收益、CAGR、年化波动、夏普、索提诺、最大回撤、卡玛、
胜率、盈利因子、平均/累计换手、期数。与 `benchmark` 渠道对照判断是否创造超额。

## 6. 记录（可审计产物）
`report.run_strategy` 为每个策略落盘：
- `README.md`：思路 / 来源途径 / 假设 / 参数 / 实现要点 / 数据与回测设置 / 结果指标表 / 净值图 / 结论与改进方向。
- `result.json`：元信息 + 指标（机器可读）。
- `equity.csv`：净值曲线。
- `equity.png`：净值图（matplotlib 可用时）。
并汇总所有策略到 `research/SUMMARY.md`。

## 7. 复现
```bash
python examples/run_all.py
```
固定 seed 的合成数据 + 确定性实现 ⇒ 任何人重跑都得到**完全一致**的记录与汇总。
要跑真实数据：`ks.load_prices_csv("your_prices.csv")` 替换 `data` 后重跑。

## 8. 迭代
基于记录的"结论与改进方向"推进：参数敏感性、样本外/滚动验证、叠加波动率目标与风控、
策略间相关性分散、成本敏感性、以及在真实数据上的稳健性检验。
