# 策略研究记录：macd_trend

> 类别/途径：**technical** ｜ 类型：timing ｜ 方向：只做多

## 一句话思路
MACD 动能：柱状图转正做多，明显转负离场（带缓冲）。

## 收集途径 / 灵感来源
经典技术分析——MACD。

## 核心假设
MACD 反映快慢动能差，柱持续为正代表上升动能占优。
